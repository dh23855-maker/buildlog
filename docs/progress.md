## 2026-10-26 Phase 2·3 구현

### 완료한 것
- 데이터베이스는 Supabase 대신 SQLite로 진행했습니다. (Supabase 연결은 Phase 13)
- Phase 2: 사용자 표(users), SQLAlchemy 연결, Alembic 구조 기록(0001), 비밀번호 Argon2 처리.
- Phase 3 서버: 회원가입, 로그인, 로그아웃, 내 정보 확인, 닉네임 변경.
  - 로그인 표(login_sessions, Alembic 0002)를 httpOnly 쿠키로 사용하고 7일 유지합니다.
- Phase 3 화면: 회원가입, 로그인, 홈, 계정 설정, 로그아웃 메뉴. 로그인하지 않으면 홈·계정 설정에 들어갈 수 없습니다.
- 자동 테스트: 서버 65개, 화면 15개 통과.
- 실제 서버(Vite 프록시 경유)에서 가입 → 로그인 → 닉네임 변경 → 로그아웃 → 예전 쿠키 거부까지 확인했습니다.
