# AI 요약 사용 안내

학습 자료함에 이미지나 영상을 올리면 OpenAI가 자동으로 내용을 요약합니다. 키만 넣으면 바로 동작합니다.

## 처음 한 번만

1. `backend/.env`에 한 줄을 추가합니다. (이 파일은 Git에 올라가지 않습니다)
   ```
   OPENAI_API_KEY=sk-로 시작하는 키
   ```
2. 데이터베이스를 최신으로 만듭니다. (`backend` 폴더, 이미 했다면 건너뜁니다)
   ```
   .\.venv\Scripts\alembic upgrade head
   ```
3. 연결을 확인합니다. (`backend` 폴더, 비용은 1원 안팎)
   ```
   .\.venv\Scripts\python -m app.tools.check_ai
   .\.venv\Scripts\python -m app.tools.check_ai --video      (영상까지 확인)
   ```
4. 백엔드를 다시 켭니다. (키를 넣거나 바꾼 뒤에는 항상 다시 켜야 합니다)
   시작할 때 `AI 요약: 사용 가능 (모델 gpt-6-luna, 하루 30회)`라고 나오면 됩니다.

패키지는 `pip install -r requirements.txt`로 이미 설치되어 있어야 합니다. (`openai`, 영상용 ffmpeg가 들어 있는 `imageio-ffmpeg` 포함, 별도 프로그램 설치 없음)

## 쓰는 방법

- 학습 자료함에서 파일을 올리면 자료가 먼저 저장되고, 몇 초 뒤 요약이 자료 아래에 나타납니다.
- 등록할 때 **"AI 요약하기"** 체크를 끄면 요약하지 않습니다. 이미 올린 자료는 **"AI 요약 만들기"**로 나중에 만들 수 있습니다.
- 요약에 실패하면 이유가 보이고 **"다시 분석"**을 누를 수 있습니다. 실패해도 자료와 파일은 그대로 남습니다.

## 설정 (모두 선택, `backend/.env`)

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| `OPENAI_API_KEY` | (없음) | 비워 두면 AI 요약만 꺼지고 나머지는 그대로 동작합니다. |
| `OPENAI_MODEL` | `gpt-6-luna` | 사용할 모델. `gpt-4o-mini`는 2027-01-14에 OpenAI가 제거할 예정이고 이미지 비용도 더 높아 권장하지 않습니다. |
| `AI_DAILY_LIMIT` | `30` | 사용자 1명이 하루(한국 날짜)에 요약할 수 있는 횟수. 자료를 지워도 돌아오지 않습니다. |

## 문제가 생기면

| 화면에 보이는 안내 | 확인할 것 |
| --- | --- |
| AI 요약 서비스에 연결하지 못했어요. 관리자 설정을 확인해야 해요. | 키가 올바른지, 폐기되지 않았는지. `check_ai`로 확인 |
| AI 요약 서비스의 사용 한도를 확인해야 해요. | OpenAI 계정의 결제·크레딧(Billing) |
| AI 요약 설정에 문제가 있어요. | `OPENAI_MODEL` 이름과 그 모델의 사용 권한 |
| 지금은 요청이 많아요 / 시간이 오래 걸렸어요 | 잠시 후 "다시 분석" |
| 오늘 AI 요약 한도(N회)를 다 썼어요 | 내일 다시, 또는 `AI_DAILY_LIMIT` 조정 |
| 서버가 다시 시작되어 요약이 중단됐어요 | "다시 분석" |
| "설정 필요"로 보임 | `.env`에 키가 있는지, 백엔드를 다시 켰는지 |

## 개인정보와 비용

- 요약을 위해 이미지(영상은 장면 일부)가 OpenAI로 전송됩니다. OpenAI는 API로 받은 데이터를 학습에 사용하지 않지만, 오남용 점검을 위해 최대 30일 보관할 수 있습니다. 요약은 올린 사람만 볼 수 있습니다.
- 한 번 요약하는 비용은 `gpt-6-luna` 기준으로 이미지 약 $0.0001, 영상 약 $0.0003입니다. 안전을 위해 OpenAI 콘솔(platform.openai.com)에서 월 사용 한도(Budget)를 함께 설정하세요.
- 키는 `.env`에만 두고 코드·문서·Git에 넣지 않습니다. 서버 기록과 화면에도 키는 나오지 않습니다.
