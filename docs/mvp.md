# BuildLog MVP 정리

## 1. BuildLog는 어떤 서비스인가요?

BuildLog는 공부와 프로젝트 기록을 한곳에 모아두는 웹사이트입니다.

메모장, AI 대화, 여러 문서에 흩어진 내용을 한곳에 저장하여 나중에 쉽게 다시 찾는 것이 목적입니다. 컴퓨터와 휴대폰 브라우저에서 모두 편하게 사용할 수 있도록 반응형 화면으로 만듭니다.

## 2. 누구를 위한 서비스인가요?

- 오늘 무엇을 공부했는지 기록하고 싶은 사람
- 앞으로 할 공부나 프로젝트 작업을 정리하고 싶은 사람
- 오류와 해결 방법을 모아두고 비슷한 문제가 생겼을 때 다시 찾아보고 싶은 사람

BuildLog는 한 사람만 쓰는 개인 프로그램이 아닙니다. 여러 사용자가 회원가입하고 각자의 기록을 관리할 수 있는 서비스입니다.

## 3. MVP란 무엇인가요?

MVP는 사용자에게 필요한 핵심 기능부터 만든 첫 번째 버전입니다.

BuildLog의 첫 MVP에서는 다음 세 가지 기록을 관리합니다.

1. 공부 기록
2. 할 일
3. 오류 기록

화려한 디자인보다 기록을 안전하게 저장하고 다시 찾는 기본 기능을 먼저 완성합니다.

## 4. 회원 기능

### 회원가입

사용자는 다음 정보를 입력해 회원가입합니다.

- 이메일
- 비밀번호
- 닉네임

### 로그인

- 가입한 이메일과 비밀번호로 로그인합니다.
- 로그인한 사용자는 자신의 기록을 만들고 관리할 수 있습니다.
- 다른 사용자의 비공개 기록은 볼 수 없습니다.

### 첫 MVP에서 만들지 않는 회원 기능

- 이메일 확인
- 비밀번호 찾기

## 5. 기록의 공개 범위

- 공부 기록, 할 일, 오류 기록은 기본적으로 `비공개`로 저장합니다.
- 비공개 기록은 작성자 본인만 볼 수 있습니다.
- 사용자가 원하면 기록을 `공개`로 설정하여 다른 사용자도 볼 수 있게 할 수 있습니다.

## 6. 공부 기록

공부 기록은 오늘 배운 내용이나 작업한 내용을 남기는 기능입니다.

### 저장하는 정보

| 항목 | 설명 |
| --- | --- |
| 제목 | 1~100자로 입력합니다. |
| 내용 | 1~5,000자로 입력합니다. |
| 공개 여부 | 기본값은 비공개이며, 사용자가 공개로 바꿀 수 있습니다. |
| 작성 날짜와 시간 | 기록을 만들 때 자동으로 저장합니다. |

### 할 수 있는 일

- 공부 기록 만들기
- 내가 작성한 공부 기록 목록 보기
- 공부 기록 자세히 읽기
- 공부 기록 수정하기
- 공부 기록 삭제하기
- 공부 기록을 공개 또는 비공개로 설정하기
- 내 공부 기록을 제목과 내용으로 검색하기
- 공개된 공부 기록 검색하기

공부 기록 목록은 최근에 작성한 기록부터 보여줍니다.

## 7. 할 일

할 일은 앞으로 공부할 내용이나 프로젝트에서 해야 할 작업을 적어두는 기능입니다.

예: `저장 버튼 만들기`, `파이썬 복습하기`

### 저장하는 정보

| 항목 | 설명 |
| --- | --- |
| 제목 | 1~100자로 입력합니다. |
| 완료 여부 | 끝내지 않았는지, 완료했는지를 표시합니다. |
| 공개 여부 | 기본값은 비공개이며, 사용자가 공개로 바꿀 수 있습니다. |
| 완료 날짜와 시간 | 완료로 체크할 때 자동으로 저장합니다. |

### 할 수 있는 일

- 할 일 만들기
- 할 일 완료 체크하기
- 할 일 수정하기
- 할 일 삭제하기
- 할 일을 공개 또는 비공개로 설정하기
- `전체`, `남은 일`, `완료한 일`로 나누어 보기

할 일 목록은 완료하지 않은 항목을 먼저 보여주고, 같은 상태에서는 최근에 작성한 항목부터 보여줍니다.

마감일과 중요도는 첫 MVP에서 만들지 않고 나중에 필요 여부를 다시 검토합니다.

## 8. 오류 기록

오류 기록은 문제가 생겼을 때 오류 내용과 해결 과정을 남기는 기능입니다. 아직 해결하지 못한 오류도 먼저 저장할 수 있습니다.

### 저장하는 정보

| 항목 | 설명 |
| --- | --- |
| 오류 제목 | 1~100자로 입력합니다. |
| 오류 내용 | 1~5,000자로 입력합니다. |
| 해결 방법 | 해결 전에는 비워둘 수 있으며, 입력할 때는 1~5,000자로 작성합니다. |
| 해결 여부 | 미해결 또는 해결 상태를 표시합니다. |
| 공개 여부 | 기본값은 비공개이며, 사용자가 공개로 바꿀 수 있습니다. |
| 해결 날짜와 시간 | 해결 상태로 바꿀 때 자동으로 저장합니다. |

### 할 수 있는 일

- 오류 기록 만들기
- 해결 전에는 미해결 상태로 보관하기
- 해결한 뒤 해결 방법 작성하기
- 오류 기록 수정하기
- 오류 기록 삭제하기
- 오류 기록을 공개 또는 비공개로 설정하기
- `전체`, `미해결`, `해결`로 나누어 보기
- 내 오류 기록을 제목과 내용으로 검색하기

오류 기록 목록은 최근에 작성한 기록부터 보여줍니다.

## 9. 공개 기록과 다른 사용자와의 소통

- 공개로 설정한 기록은 다른 사용자가 볼 수 있습니다.
- 공개 기록을 모아보는 화면이 필요합니다.
- 공개 기록에는 댓글과 좋아요 기능을 제공합니다.

댓글과 좋아요의 자세한 규칙은 개발 전에 추가로 결정해야 합니다.

## 10. 검색과 목록

현재까지 확정한 검색 범위는 다음과 같습니다.

- 내 공부 기록: 제목과 내용으로 검색
- 내 오류 기록: 제목과 내용으로 검색
- 공개 공부 기록: 검색 가능

할 일 검색과 공개된 할 일·오류 기록의 검색 여부는 아직 정하지 않았습니다.

## 11. 화면 구성 예시

정확한 디자인은 아직 정하지 않았습니다. 처음에는 다음 화면만 단순하고 알아보기 쉽게 만듭니다.

1. 회원가입 화면
2. 로그인 화면
3. 내 기록을 확인하는 홈 화면
4. 공부 기록 목록·작성·읽기 화면
5. 할 일 목록·작성 화면
6. 오류 기록 목록·작성·읽기 화면
7. 공개 기록을 모아보는 화면

화면은 컴퓨터와 휴대폰 크기에 맞게 자동으로 정리되어야 합니다.

## 12. MVP가 완성되었다고 판단하는 기준

- 사용자가 이메일, 비밀번호, 닉네임으로 가입하고 로그인할 수 있습니다.
- 사용자마다 자신의 비공개 기록이 분리되어 있습니다.
- 공부 기록을 만들고, 목록에서 찾고, 다시 읽고, 수정하고, 삭제할 수 있습니다.
- 할 일을 만들고 완료 여부를 체크하며 상태별로 나누어 볼 수 있습니다.
- 오류를 미해결 상태로 저장하고 나중에 해결 방법과 해결 상태를 기록할 수 있습니다.
- 세 종류의 기록을 기본 비공개로 저장하고 필요할 때 공개할 수 있습니다.
- 확정된 범위에서 기록을 검색할 수 있습니다.
- 공개 기록에서 댓글과 좋아요를 사용할 수 있습니다.
- 컴퓨터와 휴대폰에서 주요 기능을 사용할 수 있습니다.

## 13. 개발 전에 추가로 정할 내용

다음 내용은 아직 답이 정해지지 않았으므로 개발 전에 결정해야 합니다.

- 댓글과 좋아요를 적용할 공개 기록의 종류
- 로그인하지 않은 사람도 공개 기록을 볼 수 있는지
- 댓글의 길이, 답글 지원 여부, 수정 및 삭제 규칙
- 좋아요를 한 기록에 한 번만 누를 수 있는지와 취소 방법
- 공개된 할 일과 오류 기록도 검색할 수 있는지
- 닉네임의 중복 허용 여부와 변경 가능 여부
- 오류를 해결 상태로 바꿀 때 해결 방법을 반드시 입력해야 하는지
- 공개 기록 화면에 보여줄 기록 종류와 필터
- 공개 기록이나 댓글 신고 기능이 필요한지
- 실제 디자인과 개발에 사용할 기술

> 개발 기술은 정해졌습니다. 화면은 React, 서버는 FastAPI, 데이터베이스는 Supabase(개발·테스트는 SQLite)를 사용합니다. 자세한 내용은 `PRD.md` 10장을 참고합니다.
